# Reun Browser

A web browser for Apple Silicon Macs, built on Chromium (Electron): tabs in a sidebar, folders and
projects, split view, a password manager with passkeys, content blocking, and a built-in AI agent
that can work in your tabs.

This repository holds the builds. The browser updates itself from these releases.

## Install

Download `Reun-Browser.dmg` from the [latest release](https://github.com/reunbozdo/reun-browser/releases/latest)
and drag the app to Applications. The app is signed with an Apple Developer ID and notarized by Apple.

Or in Terminal:

    curl -fsSL https://github.com/reunbozdo/reun-browser/releases/latest/download/install.sh | sh

Requires macOS on Apple Silicon.
