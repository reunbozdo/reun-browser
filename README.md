# Reun Browser

Builds of Reun Browser for Apple Silicon Macs. The browser updates itself from these releases.

## Install

In Terminal:

    curl -fsSL https://github.com/reunbozdo/reun-browser/releases/latest/download/install.sh | sh

Or download `Reun-Browser.dmg` from the [latest release](https://github.com/reunbozdo/reun-browser/releases/latest),
drag the app to Applications, open it once, then System Settings → Privacy & Security → Open Anyway
(the build is not signed with an Apple Developer ID).
